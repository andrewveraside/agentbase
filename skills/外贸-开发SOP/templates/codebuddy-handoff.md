# CodeBuddy 交接包（模板）

> 本包由 WorkBuddy 按「外贸-开发SOP」完成开发前准备后产出，供 **CodeBuddy** 在 IDE 内直接 ingest 续写实现。
> **用法**：在 CodeBuddy 中打开本文件（或本目录），按 `SPEC → GLOSSARY → ADR → ARCHITECTURE → TEST-PLAN` 顺序阅读后开始实现。
> 既可保持单文件，也可按 `---` 分隔拆成 `SPEC.md / GLOSSARY.md / ARCHITECTURE.md / TEST-PLAN.md` 多文件。
