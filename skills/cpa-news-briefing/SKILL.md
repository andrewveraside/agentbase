# 财会税法四条线新闻简报（去重更新）

## 适用场景
- 用户要某时间窗内的新闻，且上一轮已经给过一份简报。
- 关键约束：**不重复列出上一轮已列条目**，除非属于"前后关联或引用"（即需要补充实质内容、施行日期、或后续进展）。

## 核心方法

### 1. 定窗口
先确认当前日期，再定窗口（48 小时 / 这两天 / 今日）。注意**周末效应**：财政部、税务总局、证监会周六周日基本不发文，窗口内若横跨周末，要向用户明说"官方无新发文，增量主要来自三类：①生效日新规 ②周末机构对已落地新政的解读 ③监管动态公示"。不要为了凑数把旧闻当新闻。

### 2. 四条线并行检索
用 WebSearch，`freshness` 设为 d1/d2/d3（按窗口），四条线各发一次，可在同一条消息里并行发出：

| 线 | 检索词骨架 |
|---|---|
| 财 | `财政部 会计司 会计准则 通知 <日期>` |
| 会 | `注册会计师 审计 中注协 监管 处罚 <日期>` |
| 税 | `税务总局 税收政策 增值税 公告 <日期>` |
| 法 | `证监会 新规 施行 国务院 条例 <日期>` |

**搜不到时的换法**（周末尤其常见）：改成找"早餐/早报/周报/简报"类聚合源，关键词用 `财税新闻 <日期>`、`财税行业每日重要动态`、`每日财税简报`、`财经早餐`。事务所周报（如"财税新闻周报 2026年第N期"）和国际税简报质量很高，能补出官方源没有的口径细节。

### 3. 去重的判断规则
- 上一轮只列了**文件标题**、这一轮能补**实质条款**（如判断要件、白名单/黑名单、生效日期）→ 属于"前后关联"，**要列**，并注明是补充。
- 上一轮列了**总数**、这一轮能补**结构数据**（分税种、分中央地方）→ 要列。
- 同一事件的新进展（如"将举行磋商"→"9/20 在纽约举行，议题是 X，清单预计 9/24 公布"）→ 要列。
- 同一事件无新信息 → 不列。

### 4. 输出结构（固定五段）
1. **结论先行**：一句话判断这个窗口哪条线最重、增量属哪一类。
2. **生效时点时间轴**（建议用 show_widget 画竖向 timeline）：只放有明确生效/截止日期的节点，按时间排序。这是审计人员最需要的 triage 视图。
3. **四条线分节**：财 / 会 / 税 / 法。每条尽量带：发布主体、文号、生效日期、关键数字。
4. **对当前审计项目的提示**（若已知项目）：只写 2–3 条**现在就能动手**的，不要泛泛而谈。
5. **可信度说明**：明确区分
   - 已核实：官方渠道或多源一致
   - 转述：事务所周报/机构解读，建议核对原文后再入底稿
   - 待核实：单一来源

### 5. 数字类信息的特别注意
油价、利率等**口径差异极大**（期货 vs 现货、政策利率 vs 市场利率）。引用时必须标明是哪个口径，冲突时并列呈现并说明差异原因，不要挑一个数假装权威。

## 可视化
- 每个窗口最多 1–2 个 widget，别堆。
- 优先级：①生效时点时间轴（最实用）②传导链/因果图（当新闻有单一主线时）。
- 用户连续多轮要新闻时，后面几轮可以不画 widget，纯文字更清爽。

## 可复用的判断经验
- 官方**答记者问/政策解读**往往比原文件晚 1–3 天发布，是抓"最近落地了什么"的高性价比入口。
- 地方财政局网站常转发财政部解读，且收录快，官方站还没挂时可以先在这些站看到。
- 事务所周报的"专业点评"部分会直接给出**对审计程序的影响**，比新闻本身更有用，优先看这部分。
- 处罚案例（事务所被罚/立案）来自媒体转述的，必须标注"以正式处罚决定书为准"。
