# 读法手册

先判断这份 PDF「主要怎么读」，再决定页面的骨架。下面每种读法都给出：骨架、首屏、适合的交互、「先猜再看」怎么出题、容易踩的坑。例子来自实测的 5 份材料。

## 叙事沉浸（故事、历史、传记）

- **骨架**：沿一条路线或一条时间线推进。可以做滚动叙事，也可以做单屏分幕加底部拖动条（官方演示就是后者）。
- **首屏**：一句话讲清「谁、去了哪、发生了什么转折」，配一张路线图或时间线。
  - 例（红楼梦第三回）：「没了母亲的林黛玉坐船进京，一天之内走遍外祖母家，书里最要紧的人一个个登场；最后宝玉听说她没有玉，当场把自己的玉摔了。」配宁荣二府示意图，随阅读画出她的行进路线。
- **交互**：人物出场卡（点名字看原文外貌描写）、人物关系图、地点热点（点建筑看原文陈设）、座次或礼仪的小选择题。
- **先猜再看**：「她会被拉到哪张椅子上？」「宝玉问她读过什么书，她怎么答？」
- **坑**：示意地图要标「示意」；人物和事件顺序最容易错（见准确性清单第 5、6 类）；注释用自己的话写，不要整段搬出版社的注释。

## 概念探索（概念、原理、定理）

- **骨架**：每个场景一个能动手的实验台，按「问题 → 直觉 → 定义或定理 → 应用」推进。
- **首屏**：用一句话点出核心对比或核心判定。
  - 例（七桥问题）：「每条边走一次，只要数一数奇数度的点就能判定；每个点到一次，至今没有这样的捷径。」
- **交互**：拖节点、加删边，实时显示判定结果；分步演示算法（上一步、下一步）；可旋转的立体模型；参数滑块。
- **先猜再看**：「能不能一笔走完七座桥？」「这五张图里，哪些有哈密顿回路？」
- **坑**：原文刻意区分的概念要分清（路径和回路、充分条件和充要条件）；书里的人物小传和年份可以用，书外的不要补。

## 查读（规则、手册、说明书）

- **骨架**：首屏一张全局流程图；主体是可搜索的卡片和索引，术语即点即查；要算数的地方配模拟器。不要做成线性的翻页教程，读者是来查的。
- **首屏**：一句话讲清整个流程。
  - 例（D&D 战斗）：「一场战斗其实只有一个循环：按先攻排队，轮到你就走一段、做一件事；d20 加修正够到对方护甲就打中。」
- **交互**：按意图挑卡（「我想脱身」→ 撤离、闪避）、骰子和命中率实验台、回合额度编排器、伤害结算流水线、术语索引（按 / 打开）。
- **先猜再看**：「有劣势时掷出 17 和 5，算哪个？」「站在『所有伤害减 5』的光环里挨了 25 点，实际受多少？」
- **坑**：这是最容易出错的一类。每条规则的条件、例外、主客体，都要逐条对照准确性清单第 2–5 类。模拟器的代码和旁边的文字说明要一致。

## 数据钻取（财报、数据报告）

- **骨架**：先给结论，再一层层往下钻：全局 → 分部 → 驱动因素 → 风险。
- **首屏**：一句话结论加一张「钱从哪来、到哪去」的全局图。
  - 例（可口可乐 10-K）：「它主要靠把浓缩液卖给独立装瓶商赚钱；2025 年收入 479 亿美元，只涨了 2%，增长主要来自提价和产品组合，而不是多卖。」
- **交互**：可切换维度的堆叠条（按业务线、按地区）、瀑布图拆解增长、年份切换、点分部下钻、术语卡（unit case、price/mix）。
- **先猜再看**：「卖浓缩液占 85% 的箱量，你猜它占收入的百分之几？」「全世界每天喝 650 亿份饮料，你猜其中多少是它家的？」
- **坑**：单位换算（准确性清单第 1 类）；推算出来的数（比如「每 100 美元的去向」）一定标「推算」；不要给费用下「一次性」「可持续」这类原文没说的判断；不构成投资建议。

## 论证拆解（论文、白皮书）

- **骨架**：「问题 → 方法 → 证据 → 结论」的论证地图，每个节点能点开对应的场景；方法部分配实验台。
- **首屏**：一句话讲清「做到了什么、代价是什么」。
  - 例（DeepSeek V4.1 技术报告）：「把每个 token 常驻显存的 KV 缓存压到 890 字节，约为上一代的 1/4，模型反而更强。」
- **交互**：用一个计量表贯穿全篇（读到哪个机制，数字就降一截）；层级结构可点击；上下文长度滑块推算显存占用；基准测试图可悬停读数。
- **先猜再看**：「初代模型读 100 万 token 要多少缓存？」
- **坑**：门外汉会被术语挡在外面，先打日常比方（「先圈书架，再挑书」）；从图里读出的数标「读图」；公式放进折叠层。

## 混合

很多材料是混合的：财报里的合同条款是查读，教材里的人物小传是叙事。主读法定骨架，次读法做成其中一两个场景就好。
