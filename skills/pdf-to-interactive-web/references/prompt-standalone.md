# 独立提示词（给不能装 Skill 的聊天工具）

在 Gemini、DeepSeek、ChatGPT、Kimi 这类网页聊天里用：上传 PDF（最好是其中一节），把下面整段粘贴进去，只改「风格」那一行。

## 标准版

```
把附件这份 PDF 做成一个单文件 HTML 交互网页：让我比读原文省很多时间，又舍不得关掉。界面用中文，专有名词附原文；所有画面都用代码画（SVG、CSS、Canvas），可以用 CDN 上的公开库；内容只来自这份 PDF。不要提问，一次做完。

风格：【在这里写你想要的风格，比如：中国古画、像素游戏、工程蓝图、复古海报；不写就让它自己定】

1. 先判断读法，再选交互：故事 → 跟着路线或时间线走；概念 → 能改参数、马上看到结果的实验台；规则 → 能随手查的卡片和索引；数据 → 先给结论、再往下钻的图表；论文 → 「问题 → 方法 → 证据 → 结论」的论证地图。
2. 首屏是「30 秒版」：一句大白话结论，加一张全局图。
3. 最多 7 个场景。每个场景依次是：一句话要点 → 一个能动手的交互 → 默认折叠的细节。默认能看到的文字全篇不超过 2500 字。遇到术语，先打个日常比方，再给正式说法。
4. 至少 2 处「先猜再看」：先让我猜一个数或选一个答案，再揭晓原文的答案。
5. 每个数字、每个关键说法都带出处角标，点开能看原文原句和页码；跳走以后能一键回到刚才读的位置。推算和示意的内容要标出来，不写原文没有的事。
6. 插画只画 2–4 幅大的主视觉，每幅都当成独立作品来画，把原文里的细节画进去；不要用几何形拼人物，不要卡通脸和 emoji。其余场景靠排版和图表。
7. 结尾放 3 道「你答得上来吗」。记住我读到哪里，能调字号、切换明暗，手机上也好用。
```

## 可选加强句

跑出来的页面在国内打不开字体，或者数字、规则有错时，把下面两句加在第 7 条后面：

```
8. 字体只用系统自带字体，不要引用 Google Fonts 等外部字体。
9. 转述时逐条检查：英文 billion、million 换算成亿、万有没有错位；「谁对谁」有没有说反；原句里的「除非」「只有」「且」这类条件有没有丢；有没有把一个例子说成所有情况。
```

## 用的时候

- 每个数字和规则都有角标，关键的那几处一定要点开，对一下原句。
- 一次生成不满意，可以直接说「第 3 个场景的交互改成……」，比重新生成更稳。
- 规则书、合同、财报数字这类严肃材料，建议用更强的模型，并且自己核对。
