## 工作流程

### 步骤 1 · 读地图，定检查范围
读 `E:\workbuddy\资料库\外贸知识库\_知识地图.json`，提取五类待查项：
1. `staleness[].expire` **已过**或 **±60 天内临近** → **必查**（例：2026税则 2027-01-01 失效）
2. 当前月份为 **12 月或 1 月** → 专项查"次年 / 当年关税调整方案"（税则每年 1/1 换新）
3. `gaps_ranked` 中未关闭的高优先缺口 → 抽查对应来源
4. 用户点名的具体主题 → 直接查
5. `monitored_events[]` 中每条事件的 `trigger` 是否已发生（官方公布/生效）→ 若发生，该事件升级为**高优先待更新项**，按 `on_trigger` 执行更新；执行后将该事件 `current_status` 改为"已生效"、补 `triggered_at`，避免重复触发（例：EVT-GCC-FTA 触发=补阿联酋协定税率、标记 GCC 为已生效伙伴）

### 步骤 2 · 查官方源
用 `WebSearch` / `WebFetch` 检索以下 9 个监测源（按优先级）：
1. 国务院关税税则委员会 / 财政部关税司（税则、关税调整方案；栏目 gss.mof.gov.cn/gzdt/zhengcefabu）
2. 海关总署（公告、政策解读）——归类、报关、减免税、AEO、保税
3. 国家税务总局（出口退税政策）
4. 国家外汇管理局（贸易外汇）
5. 中国国际贸易单一窗口（实时税率核对）
6. 市场监管总局（CCC 目录与免办）
7. 商务部（mofcom.gov.cn + 中国自由贸易区服务网 fta.mofcom.gov.cn）——自贸协定谈判/签署/早期收获、出口管制
8. 国家发展改革委——鼓励类产业目录、重大技术装备（减免税专项发文方之一）
9. 工业和信息化部——重大技术装备专项减免税目录

> **⚠️ 源选型门禁（2026-10-08 新增）**：优先权威原文 URL（gss.mof.gov.cn、fta.mofcom.gov.cn、customs.gov.cn、chinatax.gov.cn）；避开 JS 重渲染页（`*zwfw.gov.cn`、海外新闻站）——ima 抓取常为空，应改取权威转载或只写本地 md。

检索词按检查范围组合，示例：
- `"2027年关税调整方案" 财政部 公告`
- `"出口退(免)税" 国家税务总局 2026 公告`
- `"归类" 海关总署 公告 2026`
- `"CCC免办" 市场监管总局`
- `"自贸协定" 商务部 2026 签署`（源 7）
- `"中国 海合会 自贸协定" 签署 生效`（源 7，对应 monitored_events 的 EVT-GCC-FTA）
- `"重大技术装备" 减免税 工信部 目录`（源 8/9）
- `"鼓励类" 外商投资 进口设备 免税 发改委`（源 8）

### 步骤 3 · 比对，出库内差异
对每条搜到的官方新内容判断：
- **新内容**：库内无对应主题 → 待入库
- **新版本**：库内已有但官方出了更新 / 补充 / 废止公告 → 待更新
- **重复**：库内已有更完整版本 → 跳过
- **不重要**：地方口径或报道类 → 标记，不主动入库

### 步骤 4 · 出待更新报告（**不直接改库**）
按以下格式汇报，并**停下等用户确认**：

| 主题 | 来源 | 发布日期 | 与库内差异 | 建议动作 |
|---|---|---|---|---|
| 2027税则税率 | 关税税则委 2026-12号 | 2026-12-XX | 库内为2026版，全量换新 | 重提取（extract_v8.py lines 策略） |
| … | … | … | … | 直接入库 / 比对去重 / 成长报告 |

明确写出：共发现 **N 项**待更新，其中高置信度 **M** 项、需确认 **K** 项。

### 步骤 5 · 确认后执行更新
用户说"更新" / "全更" / 指定某项后，按 `外贸知识库/SKILL.md`「动态更新」段执行：
1. **税率更新** → `脚本工具/extract_v8.py`（⚠️ 必须 `strategy="lines"`，否则约 80% 列错位）+ `merge_v8.py` + `fix_pages.py` + `split_by_chapter.py` + `pack.py`
2. **解读 / 法规** → `mcp__ima-mcp__fetch_media_content` 或 `WebFetch` 取正文 → `parse_ima_dump.py` / `ima_fetch2md.py` 转 md（清微博/微信噪声 + 合并硬换行）→ 存 `法规实操/` 或 `ima迁入/`
3. **闭环同步**：更新 `_知识地图.json` / `.md`（coverage / files / verified / next_review / status）+ `README.md` 数字 + `pack.py`
4. **分级**：高置信度直接入库；地方口径比对去重；不确定出成长报告不入库
5. **⚠️ 入库后解析校验（2026-10-08 新增）**：`import_urls` 后必须 `get_knowledge_list` 查 `media_state` 与 `file_size`；`MEDIA_PARSING`(3) 卡死 / `MEDIA_PARSE_ERROR` / `MEDIA_PARSE_TIMEOUT` 或 `file_size=0` → 标记该 ima 条目解析失败，**本地 md 为权威**，不重推（ima 无删除，重推=重复），提示用户手动删后重推更好源。（可选）导入前去重预检：扫一遍同名/同发文字号，已存在且已解析则跳过。
